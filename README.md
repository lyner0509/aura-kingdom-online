# Aura Kingdom Online

Original landing page for `aurakingdom.online`, created with static HTML, CSS, and JavaScript.

## Local preview

Run `python -m http.server 8080` in this folder, then open `http://localhost:8080`.

## Deployment

The site is static and can be served by Nginx from `/var/www/aurakingdom.online` on the Ubuntu VPS. The server configuration is in `deploy/nginx.conf`.
